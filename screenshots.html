Screenshots

Capture once. Make it clear.

Stillmark keeps the capture and cleanup steps together, so a useful image is ready before the conversation moves on.

01 / Capture

Start with the part that matters.

Select an area, window, monitor, or the full desktop. The current capture workflow keeps the image local while you decide what to keep.

  • Area, window, monitor, and multi-monitor capture
  • Timer and repeat-last-area controls
  • PNG or JPEG output

02 / Explain

Point to the detail.

Add an arrow or a short note where the reader should look. The editor keeps common markup tools close to the canvas.

  • Arrows, lines, shapes, freehand marks, and highlights
  • Text and numbered steps
  • Blur, pixelate, spotlight, and crop

03 / Finish

Give the result some room.

Refine the presentation with a background, rounded corners, and a focused crop. Then copy the rendered image or save it where you choose.

  • Undo and redo while you refine
  • Copy to the clipboard or export a rendered image
  • Local history and save location follow your settings

04 / Editor

Everything is in view.

The editor brings the canvas, annotation tools, undo and redo, and save or copy actions into one workspace.

This preview shows the current editor surface. Final packaged-build details will be confirmed before launch.
