Privacy

A precise policy, not a broad promise.

This page records verified pre-release product behavior. It is not the final privacy policy and needs approval from the responsible publisher and policy owner.

Policy in preparation

Publisher identity, effective date, provider processing, support, website logs, retention, rights, jurisdiction, and contact details are not yet approved.

Current product data surfaces

  • User-selected screen pixels processed for capture, editing, OCR, and recording.
  • Optional cursor, click, keystroke, microphone, and system-audio processing when those recording options are enabled.
  • Saved screenshots and recordings in a user-chosen folder.
  • Bounded local history and clipboard-backing files used by enabled workflows.
  • Local settings, trial timestamps, and a machine/user-derived hash used for local trial and license binding.
  • A locally stored license record protected at rest with Windows DPAPI for the current Windows user. This protection does not enforce a device or seat limit, and software running as that user may access data the user can access.
  • Privacy-redacted local error logs whose final retention policy still needs release review.

Network scope

The current capture workflow has no cloud-upload feature. A provider-validation path exists in source, but the compiled configuration remains in offline signed mode with provider validation disabled. The final policy must document every enabled release endpoint and field separately from local capture processing.

Required before publication

The final policy must document exact locations, retention, deletion and uninstall behavior, website and checkout processing, provider identities, legal bases, international transfers, user rights, security practices, children, changes, and jurisdiction-specific disclosures.
