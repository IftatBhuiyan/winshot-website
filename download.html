Stillmark for Windows.

Capture, annotate, and record. Your 14-day trial begins when you first open the app.

The public download will open at launch.

Already have Stillmark?

Use Settings → About to check for updates included with your license. Stillmark asks before downloading and restarting. If you need to reinstall with the installer, save your work and choose Quit Stillmark from the system tray first.

Before you install

The installer is for 64-bit Intel and AMD Windows computers. It includes the application runtime and installs the Microsoft Visual C++ runtime if needed.

In the installer’s Properties → Digital Signatures, the publisher is Iftat Bhuiyan. You can compare the file’s SHA-256 checksum with the value above before running it.
